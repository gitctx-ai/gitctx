**Step 1: Add .score property to SearchResult**

- [ ] Open `src/gitctx/indexing/types.py`
- [ ] Add `@property` method to SearchResult class:
  ```python
  @property
  def score(self) -> float:
      """Primary score for ranking (hybrid > vector).

      Returns hybrid_score if available, otherwise vector_score.
      This property simplifies formatter code by providing a single score field.
      """
      if self.hybrid_score is not None:
          return self.hybrid_score
      if self.vector_score is not None:
          return self.vector_score
      return 0.0  # Fallback for edge cases
  ```
